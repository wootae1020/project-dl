# 날씨 기반 지하철 혼잡도 예측을 활용한 광고 전략 최적화

## 프로젝트 개요

이 프로젝트는 **기상 데이터와 지하철 혼잡도 데이터를 결합**해 장기 예측 모델을 만들고, 이를 바탕으로 **지하철 내 광고 전략을 최적화**하는 것을 목표로 했습니다.
2021~~2023년 서울 지하철 1~~8호선의 시간대별 혼잡도와 기상청 AWS/ASOS 관측 자료(기온, 풍향, 풍속, 강수량, 습도, 일사량, 미세먼지) 및 황사·태풍·한파와 같은 특보 데이터를 활용했습니다.

---

## 🎯 목표

1. **혼잡도 예측 모델 개발**

   * LSTM, GRU 기반 시계열 모델로 시간대·역·호선별 혼잡도를 예측
   * 기상 변화와 시간적 패턴을 반영
2. **광고 전략 수립**

   * 혼잡도가 높을 때 노출이 유리한 광고(액자형, 출입문 조명 등)와 낮을 때 유리한 광고(래핑 광고) 구분
3. **비즈니스 활용**

   * 예측된 혼잡도를 기반으로 광고비를 차등화하여 예산 효율 극대화
   * iM뱅크 수도권 고객 유입 전략 제안

---

## 데이터 구성

* **서울교통공사**: 1시간 단위 혼잡도, 호선, 역, 상·하행 구분
* **기상청 AWS/ASOS**: 기온, 체감온도, 풍향·풍속, 강수량, 습도, 일사량
* **환경데이터**: 미세먼지(PM10), 황사/태풍/한파 특보 여부
* **전처리**

  * 결측치: -99 값 처리(선형 보간, 이진 변수 생성)
  * 이상치 제거(풍향 음수 값 등)
  * 범주형 변수 원-핫 인코딩
  * MinMaxScaler, StandardScaler 적용
  * 시간 주기성 반영(Sin, Cos 변환)

---

## 모델링

* **입력 데이터**: 과거 21시간 데이터
* **출력 데이터**: 다음 1시간 혼잡도
* **구조**

  * LSTM(64) → Dropout → LSTM(32) → Dropout → Dense(Output)
  * 호선별 특성 반영을 위해 개별 모델 학습
* **튜닝**

  * Dropout: 기본 0.2, 4호선은 0.5 적용
  * Batch size: 32\~128
  * EarlyStopping, ReduceLROnPlateau 적용
* **성능**

  * R²: 94.6% \~ 97.8%
  * RMSE: 3.14 \~ 4.93

---

## 주요 인사이트

* **계절 패턴**: 여름·겨울 방학 기간 혼잡도 급감
* **요일 패턴**: 평일 > 토요일 > 일요일
* **기상 영향**: 황사 발생 시 혼잡도 약 9% 증가, 한파·태풍 영향은 제한적
* **호선별 특성**

  * 2호선: 대학·업무 밀집 지역, 종일 높은 혼잡
  * 4호선: 고척돔 경기일 야간 혼잡 급증

## 비즈니스 적용 예시

* **구일역 야구팬 타깃 광고**

  * 4\~6월, 경기 종료 후 혼잡 시간대(22시 이후)에 QR 코드 광고 배치
  * 클릭 로그 + 전환율 분석으로 최적 혼잡도 구간 산출
* **광고비 차등화**

  * 혼잡도 높은 시간대는 시야 제한 광고비↑
  * 혼잡도 낮은 시간대는 래핑 광고비↑
