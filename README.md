# 지하철 혼잡도 예측 기반 광고 전략 최적화

## 프로젝트 개요

서울 지하철은 하루 평균 700만 명 이상이 이용하는 주요 교통 수단이다. 본 프로젝트는 시간 단위 지하철 혼잡도를 딥러닝 모델로 예측하고, 그 결과를 광고 전략 수립에 활용하는 방안을 제시한다.

## 프로젝트 목표

- 기상 및 시간 정보를 반영한 지하철 혼잡도 예측
- 노선별·시간대별 예측 정확도 향상을 위한 모델 최적화
- 혼잡도 기반 광고 요금 차등화 가능성 검토
- 광고 효과 측정 및 전략 수립에의 정량적 근거 제시

## 데이터

- 분석 기간: 2021.01.01 ~ 2023.12.31
- 혼잡도: 서울교통공사 1시간 단위 열차 혼잡도 (1~8호선)
- 기상 정보: 기온, 체감온도, 풍속, 풍향, 습도, 강수량, 일사량, 미세먼지
- 기상 이슈: 황사, 한파, 태풍
- 기타 변수: 요일, 공휴일 여부, 시간(Sin/Cos), 미세먼지 등급

## 전처리 및 파생 변수

- 결측치: `-99`값 선형 보간 또는 이진 변수 처리
- 이상치: 음수값 풍향 제거
- 범주형 변수: 역명, 호선, 상하행, AWS 지점코드 인코딩
- 정규화: 입력은 MinMax, 타깃은 StandardScaler 적용
- 파생 변수: 미세먼지 등급, 공휴일 여부, 시간 주기성 변환

## EDA 주요 결과

- 혼잡도는 출퇴근 시간(07~09시, 17~19시), 평일, 황사일에 상승
- 방학 기간과 공휴일에는 혼잡도 감소
- 황사 발생 시 혼잡도 평균 약 9.29% 증가
- 호선별 혼잡도 차이 존재 (예: 2호선, 4호선 평균 높음)

## 모델 구조 및 성능

- 모델: LSTM (2층, 64 → 32 유닛)
- 입력: 과거 21시간 → 타깃 1시간 예측
- 손실 함수: MSE / Optimizer: Adam (lr=0.001)

| 구조             | RMSE      | 결정계수(R²)     |
|------------------|-----------|------------------|
| 전체 호선 모델   | 12.16     | 0.6589           |
| 전이 학습        | 13.59     | 0.5741           |
| 호선별 모델       | 3.14~4.93 | 0.9646~0.978     |

- 과적합이 발생한 4호선은 Dropout, 학습 반복 조정으로 개선 (최종 R²: 0.946)

## 활용 방안

- 혼잡도 높은 시간대: 근거리 주목 광고(예: 액자형) 우선 배치
- 혼잡도 낮은 시간대: 래핑 광고 가시성 향상
- 예: 고척돔 인근 구일역, 야구 시즌 혼잡도 예측 기반 광고 집중
- QR 코드 삽입 시 혼잡도별 클릭률 추적 가능 → 광고 효과 분석
